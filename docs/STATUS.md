## 5. Open Issues & Environmental Risks

1. **Host Physical RAM Headroom**:
   * *Status*: Docker engine containers consume ~3.32 GiB within Docker Desktop's 11.53 GiB virtual allocation. However, Docker's reported allocation/headroom is not the same as free physical host RAM. Host free physical RAM was approximately 1.35 GB at the time of measurement.
   * *Mitigation*: Physical host memory headroom is limited. We must keep all subsequent deployments (Alloy ~128Mi, Loki ~256Mi, OTel Collector ~128Mi) strictly lightweight and bounded to prevent laptop paging or memory exhaustion.
2. **Drive X: Disk Space**:
   * *Status*: Drive X: remains stable at 18.17 GB free. Images and volumes reside on Drive C: (33.7 GB free).
